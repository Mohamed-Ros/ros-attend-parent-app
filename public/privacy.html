1. المقدمة ونطاق التطبيق

مرحباً بكم في تطبيق **ROS Parent Portal** (تطبيق أولياء الأمور). نحن ندرك أهمية بياناتكم وخصوصية معلومات أبنائكم الطلاب، ونلتزم بأعلى معايير الأمان وحماية البيانات والشفافية عند تقديم خدماتنا للمؤسسات التعليمية وأولياء الأمور.

2. البيانات التي يتم جمعها

يجمع التطبيق البيانات الضرورية فقط لتقديم خدمة متابعة السجل الأكاديمي والمالي وتنبيهات الحضور، وتشمل:

  • معلومات المتابعة الحسابية: رقم الهاتف أو كود الطالب المُسجل لدى المؤسسة التعليمية للتحقق من هوية ولي الأمر.
  • سجلات الطلاب التعليمية: سجلات الحضور والغياب والتأخير، نتائج الامتحانات والاختبارات، والرسوم الدراسية والمستحقات.
  • بيانات الإشعارات (Push Notifications): توكن جهاز الهاتف (Push Token) لإرسال التنبيهات الفورية بخصوص حضور الطالب أو نزول نتائج جديدة.

3. كيف نستخدم البيانات

عرض السجل الأكاديمي

تمكين ولي الأمر من متابعة مستوى أبنائه وتفاصيل الحضور والغياب أولاً بأول.

التنبيهات الفورية

إرسال إشعارات هامة عند تسجيل الحضور والغياب أو صدور درجات امتحانات جديدة.

4. أمان البيانات والمشاركة

• تشفير الاتصال: يتم نقل جميع البيانات عبر اتصالات مشفرة ببروتوكولات (HTTPS / TLS) لضمان عدم اعتراض البيانات.

• عدم المشاركة التجارية: نحن **لا نبيع ولا نؤجر ولا نتاجر** ببيانات أي مستخدم أو طالب، ولا يتم مشاركتها مطلقاً مع أي جهات إعلانية أو خارجية.

• إعلانات الطرف الثالث: التطبيق خالٍ تماماً من الإعلانات التجاريّة.

5. حذف البيانات والحسابات

يحق لولي الأمر في أي وقت تسجيل الخروج وإزالة تفاصيل الجلسة المحفوظة محلياً. كما يحق لولي الأمر طلب حذف بيانات حسابه أو بيانات الطالب المسجلة بالتواصل المباشر مع إدارة المدرسة/السنتر التعليمي، أو عبر التواصل مع الدعم الفني.

6. التواصل معنا للدعم والخصوصية

لأي استفسارات بخصوص سياسة الخصوصية وحماية البيانات، أو تقديم طلبات حذف البيانات، يرجى التواصل مع الفريق الفني:

البريد الإلكتروني: support@ros-attends.net
